Paiement MTN MoMo — procédure manuelle
Scannez le QR code avec MTN MoMo si votre application le reconnaît comme un QR de paiement. Vérifiez le nom du bénéficiaire avant de confirmer et saisissez le montant exact affiché.

QR transmis par le propriétaire. Son statut marchand et son aptitude à recevoir des paiements commerciaux doivent être confirmés auprès de MTN avant publication.

Comment acheter ?

  1. Choisissez votre guide.
  2. Effectuez le paiement MTN uniquement si le bénéficiaire affiché est correct.
  3. Envoyez les informations de commande et la référence de transaction.
  4. Le vendeur vérifie l'encaissement dans son application MTN.
  5. Après confirmation, le vendeur vous transmet votre produit numérique.

La confirmation et la livraison ne sont pas automatiques dans cette version. Ne transmettez jamais votre code PIN MTN ni un code SMS.
